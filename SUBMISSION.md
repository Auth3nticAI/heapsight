## Short description

HeapSight is a browser-based platform that teaches C++ game development. Students write real C++ code using the raylib library, it compiles to WebAssembly on a Cloud Run service, and runs live in an HTML5 canvas &mdash; no local toolchain required. Four learning paths (RPG, Platformer, Space Shooter, Dungeon Crawler) with ~370 lessons total.

See [README.md](README.md) for full setup, prerequisites, required configuration changes, and run instructions.
