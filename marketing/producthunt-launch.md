## Description

HeapSight combines Duolingo-style gamification with real C++ systems programming.

**Why it's different:**

Most C++ courses are dry textbooks or shallow mobile apps. HeapSight is the first to combine:
- Daily streaks and achievements (like Duolingo)
- Real C++ compilation (GCC, not a toy interpreter)
- 4 industry paradigms (ECS, FSM, OOP, Embedded)
- Visual game/robot output (see your code come alive)

**What you build:**
- Space Shooter (Unity DOTS-style ECS architecture)
- Platformer (character controller with FSM)
- Simple RPG (Diablo data-driven systems)
- Robotics (ROS2 real-time programming)

**Gamification:**
- Streaks (don't break the chain)
- 15 achievements (Common -> Legendary)
- Leaderboards (weekly, all-time, streaks)
- 50 levels (Novice -> Immortal)

**Pricing:** $67 one-time for 100+ lessons (vs competitors at $240/year recurring)

**Perfect for:**
- Game developers learning C++ for Unreal/Unity
- Robotics engineers needing embedded skills
- Students building portfolio projects
- Career switchers wanting systems programming
